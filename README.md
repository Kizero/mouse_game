# 🍪 饼干保卫战 (Cookie Defense)

一个类似《吸血鬼幸存者》的Q版可爱射击游戏，玩家扮演小仓鼠站在圆形饼干中心抵御敌人入侵。

## 游戏特色

- 🎯 **圆形战场**: 独特的圆形饼干战场，360°敌人入侵
- 🐹 **可爱仓鼠**: 萌系画风，Q版角色
- 🔫 **多样武器**: 7种仓鼠主题武器（滚轮、瓜子、木屑等）
- ⚡ **爽快战斗**: 自动攻击，专注走位策略
- 📊 **成长系统**: 升级解锁新武器和能力

## 快速开始

### 安装依赖

```bash
npm install
```

### 运行开发服务器

```bash
npm run dev
```

浏览器访问 `http://localhost:3000`

### 构建生产版本

```bash
npm run build
```

## 操作说明

- **移动**: WASD 或 方向键
- **攻击**: 自动攻击最近的敌人
- **拾取经验**: 自动拾取附近的经验宝石
- **升级**: 经验满后自动升级

## 技术栈

- **游戏引擎**: Phaser 3
- **语言**: TypeScript
- **构建工具**: Vite
- **物理引擎**: Phaser Arcade Physics

## 游戏设计

### 圆形战场特色

1. **距离惩罚**: 离中心越远移速越慢
2. **碎屑区**: 饼干边缘区域会额外减速
3. **区域效果**: 中心区、中圈、外圈有不同buff

### 武器系统

#### 已实现
- **滚轮飞镖**: 围绕仓鼠旋转攻击
